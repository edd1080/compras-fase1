# Catálogo de campos como única fuente de verdad

El **catálogo de campos** es la única fuente de verdad de la que se generan el formulario del solicitante y el PDF que recibe el proveedor. Agregar, quitar o modificar un campo es carga de datos, no despliegue de código. Esto permite construir hoy con las plantillas v0.9 y sustituirlas después por las oficiales de Compras sin retrabajo. Fuente: PRD 18 §5.1/O5, doc 14 §1.
