# Nombre de producto: Portal de Compras BIA

El código interno COM-1 se mantiene (v2.0), pero el nombre de cara al usuario del producto es **Portal de Compras BIA**. La nomenclatura tentativa previa "Portal de Solicitudes de Compra" (docs 09/10) quedó descartada y actualizada. Fuentes: PRD 18, doc 12 §1, doc 22 §3.
