# Terminología canónica: "coordinador" (no "comprador")

"Coordinador de compras" es el término canónico para el individuo que gestiona la solicitud (4 personas). Se descarta "comprador" por ambiguo: podía confundirse con las 4 categorías de compra del discovery original. Quien pide es el "solicitante"; quien gestiona es el "coordinador". Fuente: PRD 18 §4, doc 22.
