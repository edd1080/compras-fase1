# Sistema autocontenido: cero integraciones con el ERP del cliente

El sistema **no lee ni escribe** en los sistemas de gestión del cliente (Dynamics/ERP) ni depende de acceso del área de tecnología de BIA. Todos los datos los genera el propio flujo. Decisión de arquitectura que eliminó la dependencia más larga del proyecto y permite construir de inmediato. Fuente: PRD 18 §5.3, doc 10 §0.
